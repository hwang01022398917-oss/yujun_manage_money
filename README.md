# 유준이 자산관리

수입·지출·저축·투자 기록, 자산·부채 현황, 목표 관리와 JSON 백업을 제공하는 설치형 웹앱입니다.

## 실행 및 설치

HTTPS 정적 웹 호스팅에 이 저장소 루트를 배포합니다. 첫 페이지는 index.html입니다.
GitHub Pages를 사용하는 경우 Settings → Pages → Deploy from a branch → main → /(root)를 선택합니다.
GitHub Free는 공개 저장소에서 Pages를 지원합니다. 개인 비공개 저장소에서는 GitHub Pro 등이 필요하며, 이 경우에도 일반적인 Pages 사이트 자체는 공개됩니다. 저장소 공개 여부는 사용자가 결정해야 합니다.

배포된 HTTPS 주소를 갤럭시 태블릿 Chrome에서 연 뒤 메뉴 → 홈 화면에 추가 → 설치를 선택합니다. GitHub 저장소 주소 자체는 앱 주소가 아닙니다.
처음 온라인으로 연 후 서비스 워커 설치가 완료되면 오프라인에서도 사용할 수 있습니다.

## 데이터

실제 금융 기록은 GitHub에 올리지 않으며 기기 브라우저 localStorage에만 저장합니다. 기기 간 자동 동기화는 없습니다. 설정에서 JSON 백업·복원을 사용하세요. 브라우저 데이터 삭제 전에는 반드시 백업하세요.
자산 잔액은 거래 내역과 자동 연동되지 않는 수동 스냅샷입니다.

## 변경

기존 앱 기능을 유지하면서 루트 진입점, 상대 경로 PWA 설정, 가로 화면 지원, 현지 날짜 및 월말 계산, 음수 금액 방지, 백업 구조 검사·복원 확인을 보완했습니다.
